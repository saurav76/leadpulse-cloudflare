# Contributing to LeadPulse

Thanks for considering a contribution. LeadPulse is an early-stage website-form presence monitor for site owners and agencies.

## Before you start

- Open an issue describing the problem or improvement, especially before large changes.
- Keep monitoring read-only. Do not submit real form entries or collect visitor data.
- Only test domains you own or are authorized to assess.
- Never commit API keys, account tokens, customer records, passwords, or environment files.
- Do not include production endpoints, customer details, or secrets in issue reports.
- Keep changes scoped and explain their impact on security, privacy, or resource usage.

## Development

1. Use Node.js 20 or later and run `npm install`.
2. Run `npm test` before opening a pull request.
3. Add tests for changes in `src/`, and document deployment changes.
4. In your pull request, summarize the change, tests run, and any breaking behavior.

## Security reports

Please do not disclose suspected security vulnerabilities in public issues. See [SECURITY.md](SECURITY.md) for reporting guidance.
